 Level 1 (Dễ)
API 1 - Continue Learning
GET /api/learning-path/continue
Business

Trả về Learning Path mà User đang học.

Response

{
   "learningPathId":1,
   "career":"Backend Developer",
   "progress":67,
   "currentSubject":"LINQ",
   "currentTopic":"GroupBy",
   "completedTopic":24,
   "totalTopic":36
}

Điều kiện

lấy theo user đăng nhập
progress tính theo Topic
current topic là topic đầu tiên chưa hoàn thành
nếu hoàn thành hết trả null

👉 API này sẽ luyện:

Join
Count
FirstOrDefault
Any
